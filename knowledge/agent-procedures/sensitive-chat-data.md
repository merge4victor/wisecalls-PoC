# DRAFT — Sensitive chat data procedure

Status: DRAFT — NOT APPROVED FOR AGENT USE

Agents must never ask customers to enter passwords, PINs, CVVs, MFA codes or recovery codes in chat. Authentication is completed in the secure sign-in interface.

If a customer sends a credential:

1. Do not repeat it.
2. Use the approved security response.
3. Follow the incident or credential-compromise procedure.
4. Escalate where required.
